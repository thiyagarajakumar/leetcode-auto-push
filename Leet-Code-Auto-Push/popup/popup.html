Connect GitHub

Automatically save your accepted LeetCode solutions directly to your own GitHub repository.

How It Works

  1. ①
    Connect Your Account Enter your GitHub Personal Access Token below.
  2. ②
    Choose a Repository Select an existing repo like my-leetcode-solutions.
  3. ③
    Configure Structure & README Choose folder mode, custom filename format, and automatic README template.
  4. ④
    Solve on LeetCode Submit a solution and get Accepted.
  5. ⑤
    Push to GitHub 🚀 Extension auto-pushes the code and maintains your repository README.

Before You Start

  • ✓ You need a GitHub account
  • ✓ Create a Personal Access Token with repo scope
  • ✓ Have a repository ready (or create one on GitHub)
